## Design influences (ideas, not code)

- Common modern marketing-site practice: clear value proposition, primary call to action, trust signals, accessible contrast, and basic SEO tags (widely discussed across public web design and Core Web Vitals guidance).
- Super-agent style delivery: productive finished zips, proactive design reviews, persistent working folders.
- Evaluation-driven checks: viewport screenshots, contrast, and "no sideways scroll" acceptance before handoff.
