# Design checklist

Use during reviews and before calling a deliverable done.

## Offer and trust

- [ ] Hero states what the firm does and who it is for in one plain sentence
- [ ] Primary call to action visible in the header on every page
- [ ] Trust signals near the top (founding year, location, team) when known

## Content honesty

- [ ] No invented clients, metrics, testimonials, or credentials
- [ ] Placeholders removed or clearly marked
- [ ] Owner writing rules followed (tone, banned punctuation)

## Accessibility and UX

- [ ] Text contrast at least about 4.5:1 on body copy
- [ ] Skip link and visible focus styles
- [ ] Mobile menu works; no sideways scroll at ~390px width
- [ ] Desktop layout sound at ~1366px width

## SEO and sharing

- [ ] Per-page title and meta description
- [ ] Canonical URL and basic social preview tags
- [ ] Organization structured data when appropriate
- [ ] `html lang` matches the default language

## Performance hygiene

- [ ] Fonts non-blocking where practical
- [ ] Scripts deferred when they are not needed for first paint
