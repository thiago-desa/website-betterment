# Workflow

1. **Brief:** URL or design doc, languages, brand rules, real facts.
2. **Diagnose:** For live sites, capture mobile and desktop issues (overflow, missing menu, weak offer, contrast, missing meta tags).
3. **Fix or rebuild:** Patch the working copy, or start `site-v2` for a larger redesign.
4. **Test:** 390 and 1366 widths, screenshots, checklist.
5. **Handoff:** Zip, open items list, wait for owner go-ahead before any deploy.
