# Skill: Website upgrade

Use when the owner asks to build, rebuild, fix, review, or propose a new version of a business website from a brief or an existing site.

1. Gather inputs: the brief or design document, the live site URL if one exists, brand rules (palette, fonts, tone, languages), and the real business facts (legal name, location, founding year, contact email, social links, team bios). Never invent facts, clients, numbers, testimonials or credentials.
2. Build or edit a static site (HTML, CSS, minimal JS, no build step) in a working folder on your computer. Keep the firm name, email and location in one config file. Keep a generator script outside the site folder so pages can be rebuilt.
3. Apply modern business site practice: a plain one-sentence value proposition in the hero, a clear primary call to action in the header on every page, trust signals near the top (founding year, location, team), a simple "What we do" section (who it is for, what they get, how it works), per-page meta descriptions, canonical and social tags, Organization structured data, accessible contrast (4.5:1), skip link, visible focus, an accessible mobile menu, non-blocking fonts and deferred scripts.
4. If the site is multilingual, set the requested default language everywhere (html lang, titles, no-JS text) and keep a toggle for the others.
5. Before delivering, remove placeholders and sample content the owner has not approved, and check that the owner's writing rules are followed across every page.
6. Test in headless Chromium at 390x844 and 1366x900. Confirm there is no sideways scroll and no script errors, and that the menu works. Save screenshots, including before and after shots for fixes.
7. Build any larger redesign as a separate copy (for example site-v2) so the current version stays intact. Zip each deliverable.
8. Never deploy yourself unless the owner asked. If another bot or person deploys, hand them the folder path, the zip and any open items to confirm, and tell the owner nothing goes live without their go-ahead.
9. Report back in plain words with screenshots, what changed, and anything the owner still needs to confirm.
